## Step 1：顺序存储二叉树

### 一、什么是树和二叉树

树是一种非线性数据结构。二叉树是每个节点最多有两个子节点的树，分别叫左孩子和右孩子。

二叉树的特点：每个节点最多两个子节点，有左右之分，不能颠倒。

### 二、顺序存储

用数组来存二叉树。为了利用数学关系，我们从下标 1 开始存根节点，这样：根节点下标为 i，左孩子下标为 2i，右孩子下标为 2i+1。

每个节点用一个结构体存，包含 data 和 used（标记这个位置有没有节点）。

### 三、函数实现

init_tree：初始化树。遍历数组把所有 used 置为 false，size 置为 0。

set_root：在 nodes[1] 处创建根节点。

set_left_child / set_right_child：传入父节点下标 parent_node，左孩子放在 2*parent_node，右孩子放在 2*parent_node+1。需要检查下标是否越界。

level_order：层序遍历。按下标顺序打印，used 为 false 打印 -1，每层末尾换行。

### 四、层序遍历的换行技巧

用一个变量 next_level 记录下一层的起始下标，初始为 2。

当 i == next_level - 1 时说明当前层结束，打印换行，然后 next_level 翻倍。

## Step 2：链式二叉树与递归

### 一、链式二叉树节点

结构体包含三个成员：int data，指向左孩子的指针 left，指向右孩子的指针 right。

创建节点时一定要用 malloc 申请内存，并且把 left 和 right 都初始化为 NULL，否则会出现野指针，导致程序崩溃（Segmentation fault）。

### 二、递归遍历

递归就是函数自己调用自己。二叉树有三种遍历顺序：

1. 前序遍历：根 -> 左 -> 右（先 printf，再递归左，再递归右）。

2. 中序遍历：左 -> 根 -> 右（先递归左，再 printf，再递归右）。

3. 后序遍历：左 -> 右 -> 根（先递归左，再递归右，最后 printf）。

三种遍历代码只有 printf 的位置不同，但执行结果完全不同。递归会有“暂停”和“返回”的过程，左子树完全走完才会去走右子树。

### Step 3: 二叉树深度与非递归遍历


用递归计算。如果节点为空返回0，否则返回左右子树深度的最大值加1。

（注意：题目给的 depth 函数里后两个 int 参数没用上，因为深度是通过递归返回值一层层冒泡传上来的，不需要指针跨层修改。）

### 二、用栈模拟非递归前序遍历

1. 创建一个栈，把根节点压入。

2. 循环：弹出栈顶节点并打印。

3. 关键：先压入右孩子，再压入左孩子（因为栈是后进先出，这样左孩子先弹出，符合前序“根左右”）。

4. 循环结束后释放栈内存。
